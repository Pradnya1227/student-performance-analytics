About This Project

StudentIQ is the presentation dashboard for a Student Performance Analytics System developed using Python, NumPy and Pandas. The analysis calculates total and average marks, assigns grades, determines results, and summarizes class and subject performance.

Grading: A ≥ 85, B ≥ 70, C ≥ 55, D ≥ 40, otherwise F. A student passes only when every subject mark is at least 40 and attendance is at least 75%.

Demonstration dataset: 20 fictional student records. This is sample data for educational purposes, not real student information.
